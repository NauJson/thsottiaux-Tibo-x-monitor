# thsottiaux-Tibo-x-monitor

Catch up on [@thsottiaux](https://x.com/thsottiaux)'s posts and replies in one place, with dated records and links back to the original conversations.

An independent, unofficial reading archive for people following Codex and AI developments. Not affiliated with or endorsed by OpenAI or Tibo.

## Start reading

- **[Latest scan](latest.md)** — check the scan timestamp and whether anything new was captured.
- **[Browse daily records](logs/)** — read captured posts, replies, and conversation context by date.
- **[Example daily record: September 16, 2026](logs/2026-09-16.md)** — see how original posts and replies are presented. This is a fixed example, not a live latest-day link.

If the latest scan says **“No new posts”**, it means that scan recorded no new items. Earlier captured content remains in the daily records.

## How to use it

1. Open a daily record and choose original posts or replies.
2. Read the parent-post context before interpreting a reply.
3. Follow the source link to check the original wording and any later updates.

An announcement or casual reply does not by itself establish that a feature is available to every account. Check the original source and your own product access before drawing conclusions.

## Contents
- [`latest.md`](latest.md): the most recent scan summary
- [`logs/`](logs/): detailed records organized by date (`YYYY-MM-DD.md`)

Records distinguish between:
- **Original posts**: posts he initiates himself
- **Replies**: his replies to other people's posts (with the original post included as context)

## Scope and limitations

This repository contains scan summaries and archived records. It does not include an installable monitoring app or the automation implementation. Scans can miss content or become stale; this is not a complete, real-time feed. Recorded engagement counts are snapshots, not live metrics.

Found a missing source or a context error? [Open an issue](https://github.com/PengZoneLab/thsottiaux-Tibo-x-monitor/issues) with the original post URL and the record to correct.
